## Decompilation

### Methodology
- **Ghidra 12.1.3** (`analyzeHeadless`) for binary decompilation
- **ARM64:** `-processor "AARCH64:LE:64:v8A"`
- **ARM32:** `-processor "ARM:LE:32:v7"`
- **Decompilation script:** `ExportFunctionsAndStrings.java` - exports function names + addresses
- **Strings extraction:** CLI `strings` tool (faster than Ghidra for large binaries)
- **Ghidra projects:** Isolated per-binary in `/tmp/ghidra_*` (deleted after completion)

## Quick Start

```bash
# Run Ghidra analysis on a binary
GHIDRA_HEADLESS_MAXMEM=512m /opt/ghidra_12.1.3_PUBLIC/support/analyzeHeadless \
  /tmp/proj proj \
  -import <binary> \
  -processor "AARCH64:LE:64:v8A" \
  -postScript ExportFunctionsAndStrings.java \
  -scriptPath <script_path> \
  -deleteProject

# Extract strings from a binary
strings <binary> | grep -iE "password|secret|key|token" > strings_output.txt
```

## Tools Used
- **Binwalk** - Firmware extraction
- **Ghidra 12.1.3** - Binary decompilation (analyzeHeadless)
- **readelf** - Binary hardening (PIE, RELRO, stack canary)
- **strings** - Credential/secret scanning
- **gitleaks** - Automated secret detection
- **Capstone** - Disassembly (fallback for Ghidra issues)
- **LZMA** - Kernel decompression

## Notes
- E5800 firmware is Qualcomm Android OTA (different from OpenWrt sysupgrade images)
- BE14000 has a full SquashFS root filesystem with 592 packages including GL.iNet SDK4 suite
- MT6000 is kernel-only (sysupgrade image, no rootfs available)
- GL.iNet custom packages (gl-sdk4-*, gl-api, gl-ui) are pre-compiled binaries, not in public gl-feeds
- All binaries are stripped; function names are auto-generated by Ghidra (except QSEE which has symbols)
